01 · Agentic AI / Recommendation Systems

SmartReco

01Problem
Learners generate a stream of behavioral signal — what they view, search, and complete — but that signal rarely turns into relevant recommendations in real time. Static category filters and one-off recommendation lists don't adapt as interest shifts.
02System
SmartReco is built around a LangGraph-based agentic workflow: learner behavior is tracked continuously, converted into category-level interest scores, and passed to a retrieval step that pulls relevant courses from a course catalog indexed in ChromaDB.
User Behavior Interest Engine Agent Retrieval Course Catalog Recommendation
03Intelligence
Interest scoring turns raw interaction events into a structured signal the agent can reason over. The LangGraph agent decides what to retrieve and when, rather than following a fixed recommendation rule — the retrieval step is a RAG pattern applied to a course catalog instead of documents.
04Engineering
The recommendation logic is served through a FastAPI backend, with course data retrieved via a Mesh API integration. Recommendations aren't just pulled on request — the system also pushes proactive digests over email and Telegram.
05Result
A working, end-to-end personalization loop — from behavioral tracking to agentic retrieval to proactive delivery — recognized with 8th place worldwide in the SmartReco Build Challenge 2026.

03 · Agentic AI / RAG

Eurus AI Copilot

01Problem
Company knowledge — public services, documents, prior proposals — is easy to lose track of, and answering questions about it accurately usually means digging through files by hand.
02System
An AI copilot built around retrieval-augmented generation over company documents.
Documents Embeddings Retrieval Agent Answer + Citations
03Intelligence
Documents are embedded and indexed in ChromaDB; retrieval grounds every response in an actual source, so answers come with citations rather than being generated from memory alone. The same retrieval layer powers drafting and summarization, not just Q&A.
04Engineering
A FastAPI backend serves the retrieval and agent logic, with a Next.js frontend as the interface for asking questions, drafting proposals, and summarizing meetings.
05Result
Company knowledge becomes queryable — grounded, citation-backed answers, plus AI-assisted proposal drafts and meeting summaries.
